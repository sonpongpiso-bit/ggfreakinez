# gg freakin ez (Fabric client mod, Minecraft Java 26.1.2)

Needs JDK 25 + Gradle 9.4+. Build with `gradle build`, jar = build/libs/ggfreakinez-1.0.0.jar
Install with Fabric Loader 0.19.3+ and Fabric API 0.155.2+26.1.2.

Hotbar needs: respawn anchor, glowstone, totem of undying.
Keys (rebindable in Controls): 2 = anchor, R = charge + shield, TAB = detonate.
Tweak AUTO_CHAIN / DETONATE_DELAY_TICKS at the top of GgFreakinEz.java.
